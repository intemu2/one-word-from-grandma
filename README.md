Entry for the [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) bounty on make.fun.

The program writes exactly one word to `/output/entry.txt`: the single word
a grandma would text about AI. Our word is **Chachi** — the name grandma
gave the chatbot, because she heard "ChatGPT" and decided it must be a
person called Chachi.

Run it with:

```sh
python3 main.py
```

It writes `Chachi` (6 bytes, no trailing newline) to `/output/entry.txt`.
